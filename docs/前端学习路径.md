## 3. 学习路径：5 个阶段，每阶段对应小站任务

### 阶段 1：模板语法 + 指令（⭐ 第 1 天）

**学什么**（对着 `views/HomeView.vue` 和 `App.vue` 现学）：
- `{{ }}` 插值：页面显示 JS 变量（你首页的 `{{ health }}` 就是）
- `v-for`：遍历数组渲染列表——**文章列表页的核心**
- `v-if / v-else`：条件显示（列表空时显示"暂无文章"）
- `:key`：v-for 必须绑定的唯一标识（性能 + 更新正确性）

**练习任务**（= README 里的练习任务 1）：
```
新建 views/ArticlesView.vue：onMounted 里 fetch('/api/articles') → v-for 渲染文章卡片
```
**验收**：localhost:5173/articles 能看到文章列表（哪怕后端文章是空的，先渲染出标题结构）

### 阶段 2：响应式 ref + 生命周期 onMounted（⭐⭐ 第 1-2 天）

**学什么**：
- `ref()`：响应式数据，改值页面自动更新（你已经用了，加深理解"为什么"）
- `onMounted`：组件挂载后执行——**每个页面"加载时拉数据"的标准写法**
- 生命周期全图（你只学了皮毛，这里补全概念）：
  ```
  创建 → 挂载(onMounted) → 更新(数据变化) → 卸载(onUnmounted)
              ↑ 我们 90% 的代码都在这里（拉数据）
  ```

**练习任务**：文章列表页里把"写死的假数据"换成"onMounted 拉后端真实数据"

**验收**：后端有文章时，列表页显示真实标题；刷新页面数据还在

### 阶段 3：axios + 封装（⭐⭐⭐ 第 3 天）

**学什么**：
- 为什么用 axios 而不是 fetch：拦截器（每个请求自动带 token）、统一错误处理
- 封装 `src/api/request.js`：
  ```js
  // 统一配置：所有请求走 /api，自动带 token，401 跳登录页
  import axios from 'axios'
  const request = axios.create({ baseURL: '/api', timeout: 10000 })
  request.interceptors.request.use(config => {
    const token = localStorage.getItem('token')
    if (token) config.headers.Authorization = `Bearer ${token}`
    return config
  })
  request.interceptors.response.use(
    res => res.data,
    err => { if (err.response?.status === 401) { /* 跳登录页 */ } return Promise.reject(err) }
  )
  export default request
  ```
- 装 axios：`cd D:/blog_project/frontend && npm install axios`

**练习任务**：把首页/文章列表页的 `fetch` 换成封装的 `request` 调用

**验收**：功能不变，但代码更干净，且登录后请求自动带 token

### 阶段 4：Vue Router 深入（⭐⭐⭐ 第 4 天）

**学什么**：
- 路由表（你已有 `router/index.js`）：加页面 = 加一行
- **动态路由**：`/articles/:id` → 文章详情页（`route.params.id` 拿 id）
- `router-link` vs 编程式导航 `router.push()`
- **路由守卫**（管理后台用）：未登录访问 `/admin` → 跳登录页

**练习任务**：文章详情页 `ArticleDetailView.vue`（`/articles/:id`，调 GET /api/articles/{id}，显示 Markdown 原文）

**验收**：点击文章卡片 → 跳详情页 → 显示对应文章内容

### 阶段 5：表单 + 管理后台（⭐⭐⭐ 第 5-6 天）

**学什么**：
- `v-model`：表单双向绑定（输入框 ↔ 变量）——管理后台写文章的核心
- `@click` / `@submit`：事件处理
- 登录流程：`POST /api/auth/login` → token 存 localStorage → 跳管理页

**练习任务**：管理后台（登录页 + 文章发布/编辑/删除 + 说说发布）

**验收**：登录 → 发文章 → 列表页看到 → 删除 → 消失，全流程闭环

## 6. 避坑清单（新手 90% 会踩）

| 坑 | 表现 | 解决 |
|---|---|---|
| `v-for` 忘了 `:key` | 控制台警告、列表更新错乱 | 永远 `:key="item.id"` |
| `ref` 忘了 `.value` | 页面不更新/取值 undefined | 模板里自动解包，**JS 里必须 `.value`** |
| 异步数据没等回来就渲染 | 页面空白、`undefined` 报错 | `onMounted` 里 await，模板用 `v-if` 判空 |
| axios 请求 401 | 明明登录了 | 拦截器没带 token / token 过期 / Bearer 没空格（后端老熟人了） |
| 跨域 CORS 报错 | 浏览器拦截 | 用 Vite 代理（已配好），前端**永远写相对路径** `/api/xxx` |
| 改代码页面不更新 | Vite 缓存 | 刷新浏览器；还不行就重启 `npm run dev` |
| 路由页面 404 白屏 | 地址对但没页面 | `router/index.js` 没注册 / `App.vue` 没写 `<router-view />` |
