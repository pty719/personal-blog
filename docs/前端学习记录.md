## 2. 核心知识模块（每块 = 概念 + 代码位置 + 一句话总结）

### 2.1 项目结构与启动

| 文件 | 职责 |
|---|---|
| index.html | 入口 HTML，`#app` 是 Vue 挂载点 |
| vite.config.js | 插件 + **`/api` 代理到后端 8000**（开发零跨域） |
| src/main.js | 创建应用 + 挂路由 |
| src/App.vue | 根组件：导航栏 + `<router-view />` |
| src/router/index.js | 路由表：URL ↔ 组件 |

**核心认知：`baseURL='/api'`（代理）让前端代码在开发/部署环境零改动。**

### 2.2 模板语法与指令

```vue
{{ health }}                              <!-- 插值：显示变量 -->
<div v-for="item in items" :key="item.id"> <!-- 列表渲染，:key 必须唯一 -->
<p v-if="loading">加载中</p>               <!-- 条件渲染 -->
<p v-else-if="error">{{ error }}</p>
<p v-else>空</p>
<a :href="friend.url" target="_blank">     <!-- 动态属性绑定 -->
<img :src="x" loading="lazy" />            <!-- 懒加载：滚动到才加载 -->
```

**踩坑：`:key` 用循环变量（`item.id`），不是数组名（`items.id`）。**

### 2.3 响应式 ref

```js
const articles = ref([])     // 响应式数据
articles.value = data.items  // JS 里改值必须 .value
// 模板里 {{ articles }} 不用 .value（Vue 自动解包）
```

**踩坑：JS 里忘写 `.value` = 页面不更新/undefined。**

### 2.4 生命周期 onMounted（每个页面的标准套路）

```js
onMounted(async () => {
  try {
    const res = await fetch('/api/xxx')
    data.value = await res.json()
  } catch (e) {
    error.value = '加载失败：' + e.message
  } finally {
    loading.value = false
  }
})
```

**三状态管理（loading / error / 数据）是生产级页面的标配**——不会白屏、不会报 undefined。

### 2.5 新建页面的固定 4 步（肌肉记忆）

```
① views/ 新建组件 → ② router/index.js 注册路由（import + 路由行）
→ ③ App.vue 菜单加项 → ④ 浏览器验证
```

**踩坑：② 最容易忘——没注册路由 = 点菜单白屏。排查顺序：组件建了没 → 路由注册了没 → 菜单加了没。**

### 2.6 动态路由（文章详情页）

```js
{ path: '/articles/:id', component: ArticleDetailView }   // 路由表
const route = useRoute()                                   // 组件里
const id = route.params.id                                 // 拿参数
```

### 2.7 axios 封装（管理后台核心）

```js
const request = axios.create({ baseURL: '/api', timeout: 10000 })
// 请求拦截器：自动带 token
request.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token) config.headers.Authorization = `Bearer ${token}`
  return config
})
// 响应拦截器：成功直接返回 data；401 清 token 跳登录
```

**价值：一次配置，所有接口自动带 token + 统一 401 处理。**

### 2.8 登录与 token

```js
localStorage.setItem('token', data.access_token)   // 登录：存
// 之后所有请求由拦截器自动带上
```

**面试点：localStorage 有 XSS 风险（脚本能读 token），生产可换 HttpOnly cookie；本项目够用。**

### 2.9 v-model 与事件

```vue
<input v-model="username" />          <!-- 双向绑定 = :value + @input 语法糖 -->
<button @click="handleLogin">登录</button>
<form @submit.prevent="handleLogin">  <!-- .prevent 阻止页面刷新 -->
```

### 2.10 路由守卫

```js
router.beforeEach((to) => {
  const token = localStorage.getItem('token')
  if (to.path.startsWith('/admin') && !token) return '/login'   // 未登录踢走
  if (to.path === '/login' && token) return '/admin'            // 已登录进后台
})
```

**面试点：前端守卫只是体验优化，不是安全——真正的安全在后端接口鉴权。**

## 3. 踩坑记录（前端，最有价值的部分）

| # | 坑 | 症状 | 原因 | 解决 |
|---|---|---|---|---|
| 1 | 组件没 import | 整个应用白屏 | router 用了未导入组件 | import 后再用；白屏先看 Console |
| 2 | `id = id++` | 编译报错 | const 不能赋值；对象要 `{}` 包 | 写 `{ id: 1, text: '...' }` |
| 3 | 字段缺失 | `undefined (reading 'slice')` | 后端返回没 created_at | Network 看 Response，对比字段（后端 schema 加回） |
| 4 | 说说包 router-link | 点进不存在的页面 | 说说没有详情接口 | 接口驱动页面：后端有什么接口做什么页面 |
| 5 | 页面改了没变化 | 旧页面 | 浏览器缓存 | Ctrl+Shift+R 强刷 |
| 6 | 外链图片慢 | 页面卡 2 秒 | 图床 1.9s 下载 | loading="lazy"；生产用 OSS/CDN |
| 7 | 127.0.0.1 打不开 | 连接拒绝 | Vite 绑 localhost（IPv6 ::1） | 访问 localhost:5173 |
| 8 | 接口返回数组 vs 对象 | 列表空 | friends/projects 返回 `[...]` 不是 `{total,items}` | curl 看返回结构，直接 `res.json()` 赋值 |

## 4. 面试速记（前端部分）

| 问题 | 回答 |
|---|---|
| v-if 和 v-for 哪个优先级高？ | v-for 高（同元素别一起用，会有性能/逻辑坑） |
| ref 和 reactive 区别？ | ref 包基本类型/对象（.value 访问）；reactive 只包对象 |
| :key 有什么用？ | 虚拟 DOM diff 的唯一标识，保证列表更新正确 |
| v-model 原理？ | :value + @input 语法糖 |
| 组件通信？ | 父传子 props（defineProps）、子传父 emit（defineEmits） |
| 为什么 axios 不是 fetch？ | 拦截器、统一配置、错误处理 |
| 前端能防住未登录访问吗？ | 不能，只是体验；安全在后端 |
| v-html 风险？ | XSS；只渲染可信内容（自己库里的数据） |
